# thot-security

Monorepo que consolida los servicios `cryptotrace` y `hps-system` en un único repositorio.

## Estructura
```
thot-security/
├── cryptotrace/          # Plataforma Django + microservicios OCR/Processing/PDF
├── hps-system/           # Frontend React + Backend integrado en Django
└── docs/                 # Documentación organizada
```
